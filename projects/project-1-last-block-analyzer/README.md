# Last Block Analyzer

## What this does
A small Python tool that fetches data from the latest Bitcoin block and
extracts simple, useful metrics.

## Why I built it
To move beyond theory and learn how real Bitcoin data is structured and accessed.

## Features
- Fetches latest block data via mempool API
- Parses transactions and block metadata
- Outputs readable metrics

## Tech
- Python
- Public Bitcoin API

## What I learned
- How block data is structured
- How to work with Bitcoin APIs
- Where my code needs improvement
